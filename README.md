This project is a GUI-based Traffic Signal Simulation System developed for the Operating Systems (CSC322) course. It simulates a real-world four-way traffic intersection with multiple vehicle types, traffic lights, deadlock handling, and emergency vehicle priority.

The system is built using Python with Tkinter and demonstrates core Operating System concepts such as process synchronization, concurrency control, deadlock detection, and recovery mechanisms.

It provides an interactive simulation where vehicles move according to traffic signals, emergency vehicles (ambulances) are given priority, and traffic congestion scenarios are handled intelligently through deadlock detection and resolution strategies.
